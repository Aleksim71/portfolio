Tempasi — Template Marketplace

fullstack · case study

A marketplace for website templates with two access models: rent, or buy exclusively — each template can be sold only once. Sellers upload a ZIP through the Cabinet; the app validates it, extracts a preview for the catalog and serves a live demo from storage. Uri — Scenario Engine

backend · systems design

A small automation engine that runs JSON-defined scenarios: an actor delegates each step to a handler, a critic turns the result into continue/terminate — nothing smarter than that on purpose. Triggers resolve through a cascade of registries; guards stop runaway scenarios, and every failure takes one path to an onError hook. Built on it: a watcher that polls the Freelancehunt API and notifies me via Telegram and email, with at-least-once delivery. Covered by 37 tests.
